# 🏡 Property Post Maker

> Built for the **MLH Claude Intern Role Practical Task** by **Mayank** using **Claude Code**.

An automated tool that instantly turns **4 simple input fields** into ready-to-share, designed social media marketing creatives with luxury branding and contact details automatically embedded.

---

## ✨ Features

- **4 Core Input Fields**:
  - `Property & Type` (e.g. *4 BHK Luxury Villa, Ansal Golf City*)
  - `Location` (e.g. *Sushant Golf City, Lucknow*)
  - `Price` (e.g. *₹2.5 Cr onwards*)
  - `Highlights` (e.g. *3000 sq.ft · Corner plot · Ready to move*)
- **Auto-Added Branding & Contact Line (Zero Typing Needed)**:
  - Header brand bar with agency logo (`VERTEX ESTATES - Luxury Real Estate`).
  - Contact footer with Phone, Website, and RERA verification.
  - Creator watermark & header badge: *Built with Claude Code by Mayank*.
- **5 High-End Luxury Themes**:
  - 🌙 Midnight Gold (Dark Glassmorphism)
  - 📰 Editorial Luxe (Modern Editorial Serif)
  - 🌿 Emerald Modern (Architectural Emerald)
  - 🌅 Sunset Terracotta (Mediterranean Villa)
  - 💎 Royal Sapphire (Corporate Prestige)
- **4 Social Media Ratios**:
  - `1:1 Square` (Instagram Feed)
  - `4:5 Portrait` (Instagram Post)
  - `9:16 Story` (Instagram / WhatsApp Story)
  - `16:9 Banner` (Twitter / LinkedIn)
- **1-Click High-Res PNG Export** (with confetti celebration).
- **1-Click Copy Image to Clipboard**.
- **AI Social Caption Generator** for Instagram & WhatsApp.

---

## 🛠️ Tech Stack

- **React 19** + **Vite**
- **Lucide Icons**
- **html-to-image** + **canvas-confetti**
- **Modern Vanilla CSS** (Tailored Glassmorphism, Google Fonts)
